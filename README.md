# Secure-Password-Generator

Консольная утилита на C++ для генерации стойких паролей, расчета их энтропии и оценки времени взлома методом brute-force.

## Возможности
- Генерация паролей: использование std::random_device и std::mt19937 для высокой случайности.
- Оценка стойкости: расчет информационной энтропии пароля и примерного времени взлома.
- Сохранение результатов: запись сгенерированных паролей и параметров в файл passwordBase.txt.

## Стек технологий
- Язык: C++20
- Библиотеки: STL (iostream, cmath, random, fstream, string)
- Сборка: CMake
