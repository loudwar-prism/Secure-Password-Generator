# Secure-Password-Generator

Консольная утилита на C++ для генерации стойких паролей, расчета их энтропии и оценки времени взлома методом brute-force.

---

 ##Возможности
Генерация паролей: использование std::random_device и std::mt19937 для обеспечения высокой случайности комбинаций.
Оценка стойкости: расчет информационной энтропии пароля и примерного времени взлома.
Сохранение результатов: автоматическая запись сгенерированных паролей и их параметров в текстовый файл passwordBase.txt.

---

 ##Стек технологий
Язык: C++17 / C++20
Библиотеки: STL (<iostream>, <cmath>, <random>, <fstream>, <string>)
Сборка: CMake / MSVC / GCC / Clang
