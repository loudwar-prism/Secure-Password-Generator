# Secure-Password-Generator

Консольная утилита на C++ для генерации криптографически стойких паролей, расчета их информационной энтропии по Шеннону и оценки времени брутфорс-взлома.
---
**Особенности:
Стойкая генерация: Использование аппаратного генератора случайных чисел random_device и алгоритма mt19937 вместо устаревшего rand().
Расчет энтропии: Вычисление энтропии пароля по формуле Шеннона $E = L \cdot \log_2(R)$.
Оценка брутфорса: Динамический расчет времени взлома подбором при скорости атаки $10^{10}$ комбинаций/сек.
Логирование: Безопасное сохранение сгенерированных ключей и их метрик в текстовый файл passwordBase.txt.
Защита от переполнения: Использование типа double для обработки комбинаций порядка $10^{24}+$ и предотвращение integer overflow при касте времени.

---

Язык: C++20
